# Rashi Gupta — React Portfolio

A responsive personal portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
npm run preview
```

## Customize

Open `src/main.jsx` and update:

- Email placeholder
- Project descriptions/links
- GitHub link
- Additional certifications
- Skills
- About text

The current content is based on publicly visible information from the supplied LinkedIn profile plus project information supplied by the owner in the conversation.

## Main stack

- React
- Vite
- Lucide React
- CSS
